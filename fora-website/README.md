# FORA – Innovating Healthcare Management

Νέος ιστότοπος για το ετήσιο υβριδικό forum της CMT Prooptiki, σε αντικατάσταση του παλιού WordPress (healthcare-management.gr).

## 📖 Ξεκινήστε από εδώ
Ανοίξτε το αρχείο **`../SETUP-GUIDE.md`** (στον φάκελο `Fora`). Είναι πλήρης οδηγός βήμα-βήμα για μη τεχνικό χρήστη.

## Δομή

```
fora-website/
├── backend/   Πίνακας διαχείρισης περιεχομένου (headless CMS).
│              Εδώ συνδέεστε και επεξεργάζεστε τα πάντα μέσω φορμών.
└── frontend/  Ο δημόσιος ιστότοπος (Next.js). Διαβάζει το περιεχόμενο από
               το Strapi και παράγει πανγρήγορες στατικές σελίδες.
```

> Σημείωση: παλαιότερα ο ιστότοπος ήταν φτιαγμένος σε Astro. Πλέον είναι σε **Next.js**
> (φάκελος `frontend/`). Αν έχει μείνει ένας παλιός φάκελος `astro/`, μπορείτε να τον σβήσετε.

## Τι έχει ρυθμιστεί ήδη

- **Χρώματα & εμφάνιση** βασισμένα στα χρώματα της μάρκας (μπλε `#0d4f9f`) και στις γραμματοσειρές του υπάρχοντος ιστότοπου (Hagrid, Cambo, Lato).
- **Τύποι περιεχομένου Strapi** με ελληνικά ονόματα πεδίων:
  - **Forum (Διοργάνωση)** — μία εγγραφή ανά χρονιά, με θέμα, ημερομηνία, χώρο, διακόπτη «Τρέχον Forum», θεματικές ενότητες, ομιλητές (φωτ./βιογραφικό), συνεργάτες (λογότυπα ανά κατηγορία), φωτογραφίες, βίντεο, ατζέντα PDF.
  - **Ρυθμίσεις Ιστότοπου** — λογότυπο, email, τηλέφωνο, Facebook, LinkedIn.
  - **Εγγραφή Newsletter** — αποθηκεύει τα emails από τη φόρμα του ιστότοπου.
- **Αυτόματη εισαγωγή περιεχομένου** (`npm run seed` στο `backend/`) που κατεβάζει όλες τις εικόνες/PDF από τον παλιό ιστότοπο και δημιουργεί τα Forum 2022–2025 με πραγματικό περιεχόμενο.
- **Σελίδες ιστότοπου (Next.js):** Αρχική (τρέχον Forum), «Προηγούμενα Fora» (αρχείο), και μία σελίδα ανά προηγούμενη διοργάνωση.

## Τεχνικές σημειώσεις (για προγραμματιστή/διακομιστή)

- Strapi v5 (Node 18–22). Βάση: SQLite για τοπικά, PostgreSQL για production (ρυθμίζεται με `DATABASE_CLIENT` στο `.env`).
- Τα δικαιώματα ανάγνωσης (public) ορίζονται αυτόματα στο `src/index.js` — δεν χρειάζεται API token για τον ιστότοπο.
- **Next.js 14 (App Router)** σε λειτουργία `output: 'export'` (στατικός ιστότοπος). Διαβάζει το Strapi μέσω REST κατά το build και παράγει τον φάκελο `out/`.
- Ρύθμιση διεύθυνσης Strapi: `NEXT_PUBLIC_STRAPI_URL` στο `frontend/.env.local`.
- Οι γραμματοσειρές Adobe Typekit ορίζονται με `NEXT_PUBLIC_TYPEKIT_URL` (βλ. SETUP-GUIDE.md).
- Ο δημόσιος ιστότοπος τρέχει τοπικά στη θύρα **4321** (`npm run dev`).
